# Marci Metzger — Homepage Redesign

A responsive homepage redesign for Marci Metzger of
The Ridge Realty Group, created as a take-home assignment
for the Junior Website Builder position at Luxury Presence.

## Live Demo

[View the deployed website] https://marcimetzger-ixxei4go6-pooxhis-projects.vercel.app/

## Project Overview

This redesign presents a refined, luxury-inspired real estate
experience focused on visual storytelling, responsive layouts,
and intuitive interactions.

The page includes an introduction to Marci Metzger, buyer and
seller information, a property-search interface, an interactive
property photo gallery, service highlights, and contact details.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Editorial-style hero and content sections
- Interactive property gallery with directional transitions
- Hover and focus micro-interactions
- Scroll-triggered reveal animations
- Contact and property-search demo interactions
- Custom favicon and branded visual styling

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Vercel for deployment

## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

    git clone https://github.com/pooxhi/luxper.git

Navigate to the project directory:

    cd luxper

Install dependencies:

    npm install

Start the development server:

    npm run dev

## Production Build

Generate an optimized production build:

    npm run build

Preview the production build locally:

    npm run preview

The production files are generated in the `dist` directory.

## Demo Limitations

The property-search interface is a demonstration and is not
connected to a live property-listings service.

The contact form demonstrates browser validation and interface
feedback but does not send or store messages.

## Project Notes

This project is a homepage redesign prepared for a take-home
assignment. Property information and imagery are presented
for demonstration purposes; contact the real estate professional
directly for current listings and property details.
